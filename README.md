# Артём Гусев — лендинг

Одностраничный лендинг перформанс-маркетолога для девелоперов. Тёмный «дашборд»-стиль, адаптив, один файл.

- **Стек:** статический HTML/CSS, без сборки и зависимостей.
- **Шрифты:** Manrope / Inter / JetBrains Mono (Google Fonts).
- **Запуск:** открыть `index.html` в браузере.

## Структура
- `index.html` — вся страница (hero, «с кем работаю», результаты, как работаю, манифест, CTA).
- `assets/` — портреты для hero и CTA.
